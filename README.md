# 출장 서무비서 AI-Trip Pass

2026 공공 AI 대전환 챌린지 · 세션 2 · 과제② 서무비서 출품작 (국립원예특작과학원)

출장 관련 상황을 말하면 규정 근거와 함께 절차·기한·필요 서류를 안내하고, 하이패스 영수증과 현장사진으로 여비를 산정·검증한 뒤 출장이행확인서까지 작성합니다.

## 접속 주소

- 온라인 실행: [담당자 확인 요망: Streamlit 앱 주소 기입]
- 별도 설치 없이 브라우저(Chrome, Edge 권장)에서 바로 사용합니다.

## 주요 기능

| 탭 | 하는 일 |
| --- | --- |
| 💬 출장 서무비서 | 상황 질문 → 업무 절차(순서·기한·서류) 안내, 필요한 서식 내려받기, 출장일 기준 기한 날짜·진행 상황·다음 할 일, 근거 조문 원문, LLM 답변의 인용 조문 검증 |
| 📄 영수증 처리 · 확인서 작성 | 하이패스 영수증 PDF 여러 건 자동 합산, 출발지·목적지 추정, 출장일 유가로 유류비 산정, 출장 기간·숙박에 따른 일비·식비·숙박비(지역별 상한) 계산, 출장이행확인서 PDF 생성 |
| 📍 현장사진 위치 증빙 | 기관 소재지에서 출장지까지 다녀왔는지 사진 위치정보(EXIF)로 확인, 여러 장 판정, 촬영일·출장일 대조, 이동 경로 지도, 사진 위치 기준 유류비 산정·확인서 생성 |
| 📊 관리자 대시보드 | 제출 건의 자동 승인·수기 확인 현황 |
| ⚙️ 기관 설정 | LLM 교체, 규정 파일 추가·제외, 서식 추가·제외, 규정에서 업무 절차 초안 자동 생성(LLM 또는 규칙 기반)·수정·적용, 기준 유가·도로계수·허용 반경·자동 승인 기준, 설정 내보내기·불러오기 |

## 실행 방법

### 온라인 (권장)
접속 주소로 들어가 `mock_data` 폴더의 모의 파일로 아래 순서를 따라 합니다.

1. **출장 서무비서**: "출장 다녀와서 정산해야 해요" 버튼 → 절차와 근거 조문 확인
2. **영수증 처리**: `모의영수증_음성-인천_6건.pdf` 업로드 → 통행료 15,300원·음성→인천 자동 인식 → 차종 선택 → PDF 생성
3. **현장사진 위치 증빙**: 모의 사진 2장을 함께 업로드 → 인삼특작부에서 출장지까지의 거리, 출장지 방문 확인(인천 사진)과 수기 확인 표시(대전에서 찍은 사진), 이동 경로 지도 확인

### 로컬 PC
```bash
pip install -r requirements.txt
streamlit run ai_trip_pass_app.py
```
Python 3.10 이상. 출장이행확인서 PDF의 한글 글꼴은 자동 적용됩니다(나눔고딕 → Windows 맑은 고딕 → 나눔고딕 자동 내려받기 순).

## LLM 연결과 교체 (모델 비종속)

- 모든 모델 호출은 `llm_client.py`의 OpenAI 호환 규격(`/v1/chat/completions`) 하나로 합니다. **주소·모델명·키만 바꾸면** 모델이 바뀝니다.
- 연결하지 않아도 서무비서는 규정 검색만으로 절차와 근거를 안내합니다(핵심 기능은 LLM 없이 동작).
- 화면에서 바꾸기: `기관 설정` 탭 → 모델 선택 → 주소·모델명 입력 → `연결 테스트`
- 배포 환경 기본값(Streamlit Secrets):
  ```toml
  LLM_BASE_URL = "https://<OpenAI 호환 주소>/v1"
  LLM_MODEL = "<모델명>"
  LLM_API_KEY = "<키>"
  ```
- 로컬 2종 모델 구동 예시(Ollama):
  ```bash
  ollama pull gemma3:4b
  ollama pull exaone3.5:7.8b
  ```
  `기관 설정`에서 "Ollama · Gemma 3" 또는 "Ollama · EXAONE 3.5"를 고르면 됩니다.

## 기관 맞춤 설정

- **규정**: `regulations/`의 기본 규정은 시연용 모의 지침입니다. 실제 운영 시 기관 여비 규정 원문(md, txt, pdf, hwpx)을 `기관 설정`에서 추가하고 모의 지침은 해제합니다.
- **절차**: 규정을 넣고 '규정에서 절차 초안 만들기'를 누르면 단계·기한·서류·근거가 정리된 초안이 나오고, 담당자가 고쳐 적용합니다. `regulations/procedures.json`으로 직접 관리할 수도 있습니다.
- **서식**: `forms/`의 기본 서식(시연용 모의 4종) 외에 기관 서식(hwpx·hwp·docx·xlsx·pdf)을 추가하면, 절차 단계의 서식 이름과 연결되어 서무비서가 내려받기를 제공합니다.
- **기관 소재지(기준점)**: 기관명·소재 시·군·좌표를 정하면 출발지 기본값과 위치 검증 기준점에 쓰입니다(기본: 국립원예특작과학원 인삼특작부, 음성).
- **여비 기준표**: 일비·식비(1일), 숙박비 지역별 상한(서울·광역시·그 밖), 근무지 내 출장 금액을 설정합니다. 기본값은 시연용이므로 「공무원 여비 규정」과 기관 지침의 최신 금액으로 확인해 입력합니다.
- **기준값**: 기준 유가, 도로계수, 위치 허용 반경, 자동 승인 기준 금액을 설정 탭에서 정하고 JSON으로 내보내 기관 간에 공유합니다.

## 알려진 제약

- 이동거리는 시·군 좌표 간 직선거리 × 도로계수(기본 1.3) 추정값이며, 화면에서 수정할 수 있습니다.
- 영수증 인식은 한국도로공사 하이패스 영수증 PDF 양식(텍스트 포함)에 맞춰져 있습니다. 스캔 이미지 영수증은 지원하지 않습니다.
- 기본 탑재 규정·절차의 기한(예: 복귀 후 7일)은 모의 값입니다.
